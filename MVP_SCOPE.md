# MVP Scope

## MVP Name

CareerSetu

Working tagline:

Discover jobs. Understand the work. Learn the skills. Apply with confidence.

## MVP User Flow

1. User enters:
   - Education level
   - State
   - Current skills
   - Career preference

2. Platform recommends:
   - Jobs/careers available now
   - Jobs/careers reachable after short training
   - Government exams or apprenticeships

3. User opens a career:
   - Plain explanation
   - Daily work
   - Required skills
   - Eligibility
   - Salary range
   - Roadmap
   - Learning resources
   - Apply links

4. User sees:
   - Skill gap
   - 30/60/90-day roadmap
   - Free learning resources
   - Relevant opportunities

## MVP Career Categories

Start with practical, high-reach careers:

- Data Entry Operator
- Customer Support Executive
- Electrician Apprentice
- Solar Technician
- Nursing Assistant
- SSC CHSL Candidate
- Railway Group D Candidate
- Banking Correspondent
- Delivery/Logistics Coordinator
- Retail Sales Associate

## MVP Data Sources

Use curated seed data first, then connect sources.

Initial source categories:

- National Career Service
- SSC
- UPSC
- RRB
- IBPS
- Apprenticeship India
- SWAYAM
- NPTEL
- Skill India
- YouTube Data API
- O*NET
- ESCO

## Out of Scope for First MVP

- User login
- Real-time scraping at scale
- Payment
- Resume parsing
- Full multilingual support
- Production-grade AI assistant

These should come after the product flow and data model are validated.
