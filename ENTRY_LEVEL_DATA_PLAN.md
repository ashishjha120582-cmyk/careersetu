# Entry-Level Data Plan

## Current Product Direction

The first real version should be a practical career mapper, not a large-scale job board.

We will collect a limited job/opportunity dataset, then use an LLM to help users understand:

- What the job is
- Whether they are eligible
- What skills are needed
- What they already know
- What they need to learn
- How to learn it
- How to apply

The first target is 300-400 opportunity records focused on:

- Freshers
- No-experience users
- 10th pass, 12th pass, ITI, diploma, graduate users
- Jobs, apprenticeships, public exams, and local livelihood opportunities
- Salary/stipend mostly under Rs 50,000 per month

## Important Constraint

We do not have the budget to scrape every source repeatedly.

So the first dataset should be:

- Small enough to maintain
- Broad enough to demonstrate value
- Source-linked
- Refreshable weekly or manually
- Strong enough for LLM-based job explanation and roadmap generation

## What We Are Building First

User says:

> I am 12th pass. I know typing and basic computer. I live in Bihar. I want a job soon.

System returns:

- Jobs they can apply for now
- Government/exam paths they can prepare for
- Apprenticeships they can enter
- Skills missing for each path
- Roadmap generated by AI using job context
- Learning resources
- Apply/source links

## Dataset Size Target

| Segment | Target records | Purpose |
| --- | ---: | --- |
| Private entry-level jobs | 120-150 | Immediate employment |
| Government jobs/exams | 60-80 | Public sector pathways |
| Apprenticeships/internships | 50-70 | Low-experience entry route |
| Skill/course-linked opportunities | 40-50 | Learn then apply |
| Self-employment/local livelihood paths | 30-50 | Rural and small-town relevance |

Total target: 300-400 records.

## Education Split

| Education level | Target records | Example paths |
| --- | ---: | --- |
| 10th pass | 60-80 | delivery, warehouse, electrician apprentice, retail, railway group D |
| 12th pass | 100-120 | data entry, SSC CHSL, customer support, banking correspondent |
| ITI | 60-80 | electrician, fitter, welder, solar technician, machine operator |
| Diploma | 40-60 | technician, junior engineer apprentice, field service |
| Graduate | 60-80 | customer support, sales trainee, bank apprentice, operations associate |

## Salary/Experience Filter

Default inclusion rules:

- Experience: 0-2 years
- Salary: under Rs 50,000/month where salary is available
- Include stipend roles if they provide employability value
- Exclude senior, manager, specialist, and high-bar roles unless useful as a growth path

## Opportunity Record Fields

Every job/opportunity should store:

| Field | Why it matters |
| --- | --- |
| title | Display and matching |
| source_type | private_job, govt_exam, apprenticeship, internship, scheme, self_employment |
| source_name | NCS, SSC, JobSpy, Apify, Apprenticeship India, etc. |
| source_url | Trust and apply link |
| organization | Employer/department/platform |
| location | State, district, remote, all India |
| education_required | Eligibility matching |
| experience_required | Fresher filter |
| salary_or_stipend | User decision support |
| last_date | Critical for public jobs |
| description | LLM context |
| responsibilities | Job understanding |
| eligibility | User eligibility check |
| skills_raw | Extracted from source |
| skills_normalized | Matching and gap analysis |
| documents_required | Application readiness |
| selection_process | Exam/interview/training |
| category | office, trade, govt_exam, healthcare, logistics, etc. |
| freshness_date | Data quality |
| confidence | high/medium/low |

### Government Jobs and Exams

Use official portals/pages and notification PDFs.

First public paths:

- SSC CHSL
- SSC MTS
- SSC GD
- RRB Group D
- RRB NTPC undergraduate-level where applicable
- IBPS Clerk
- State police constable
- State PSC lower-division/clerical roles
- Postal/GDS-type opportunities where active and official

Store them as career/exam paths even when current applications are closed.

### Apprenticeships

Use:

- Apprenticeship India / NAPS
- NATS
- Bank apprenticeships when available
- PSU apprenticeships when available
- PM Internship Scheme if relevant

Apprenticeships are important because many users lack experience.

### Learning and Skill Sources

Use:

- YouTube Data API for Hindi/regional videos and playlists
- SWAYAM/NPTEL curated courses
- Skill India/SIDH where accessible
- Manual resources for the first 20 careers

The learning resource must map to missing skills, not just the job title.

## LLM Role

The LLM should be used heavily, but with boundaries.

### LLM Can Do

- Explain job descriptions in simple language
- Extract required skills
- Group skills into beginner/intermediate/advanced
- Generate a 30/60/90-day roadmap
- Suggest what to learn first
- Generate user-specific answers from job context
- Translate to Hindi or simple English
- Convert a government PDF into understandable steps

### LLM Must Not Do

- Invent active vacancies
- Invent salary
- Invent official deadlines
- Invent apply links
- Claim eligibility without source context

## Bot Input Context

When user asks about a job, send the LLM:

- User profile
- Opportunity record
- Related occupation record if available
- Extracted skills
- Known missing skills
- Available learning resources
- Source URL and source date

## Bot Output Format

For every job/career, the bot should answer:

1. What this job means
2. What work you will do daily
3. Whether you are eligible
4. What skills you already match
5. What skills you need to learn
6. 30-day roadmap
7. 60-day roadmap
8. 90-day roadmap
9. Free/low-cost learning resources
10. How to apply
11. Documents to keep ready

### Ingestion Scripts

Create:

- `scripts/ingest_govt_notifications.py`
- `scripts/normalize_opportunities.py`

### Product Flow

1. User enters simple profile.
2. System filters records by education, salary, experience, location, and path.
3. System shows 3 buckets:
   - Apply now
   - Learn then apply
   - Exam/apprenticeship path
4. User opens a role.
5. LLM explains the role and creates a roadmap.
6. User sees apply link and learning steps.

## Low-Cost Refresh Plan

Because scraping is expensive:

- Refresh private jobs weekly, not continuously.
- Keep only entry-level jobs under Rs 50k.
- Deduplicate by title + company + location + apply URL.
- Archive expired jobs.
- Keep government exam paths even when inactive.
- Refresh official public notifications manually or weekly.
- Let the LLM work from cached job data.

## Success Criteria

The MVP is useful if a user can say:

> I only know my education and skills, and now I understand which jobs I can try, what I need to learn, and what to do next.

That is the core product.
